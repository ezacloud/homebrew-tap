# Eza Cloud Homebrew Tap

Official Homebrew tap for the [Eza Cloud](https://eza.co.ke) command-line interface.

## Installation

```bash
brew tap ezacloud/tap
brew install eza
```

Or install directly with a single command:

```bash
brew install ezacloud/tap/eza
```

## Quick Start

```bash
# Verify installation
eza version

# Authenticate terminal
eza login

# Deploy your app
eza deploy
```

For full documentation and guides, visit [eza.co.ke/docs/cli](https://eza.co.ke/docs/cli).
